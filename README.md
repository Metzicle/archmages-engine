# The Archmage's Engine: The Last Archmage
Issue tracker for The Archmage's Engine modpack (NeoForge 1.21.1).
## Found a bug?
1. Open a new issue.
2. Say what happened and what you were doing.
3. Include your pack version and whether you were in singleplayer or on a server.
4. Drag in your logs/latest.log, plus the file from crash-reports if the game crashed.
Suggestions are welcome too!
